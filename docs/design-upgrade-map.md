## Source discrepancies resolved

- Active frontend is `resume-tailor-ui-github`, not the export's `roleforge-ai-main` path; backend is `resume-tailor-backend` and was clean at start.
- Export says themes reset; actual `ThemeToggle` and root layout already persist `roleforge-theme`. Preserve that key and pre-paint behavior, not prototype `rf-theme`.
- Export says no logo asset; actual app already has `app/icon.svg`. The new supplied mark is an authorized replacement, not a missing-feature repair.
- Several reference buttons retain white text on amber even though the README corrects it. Use `--on-brand` and `--brand-hover` for readable action states.
- Token table and older design-system prose disagree. Current `tokens/colors.css` and the final screen values are the visual source; verify rendered contrast instead of repeating the bundle's audit claims.
- Prototype CTA `#studio` opens a sample; the real app's Build action must keep its signed-in `/app` or signed-out `/login?next=/app` destination.
- Preserve the pending fresh-export readiness and retained landing-demo patches. Source/unit tests do not settle the remaining mobile reopening timing and hidden-content keyboard checks.
- Do not import support.js, inline runtime compilation, matchMedia polling, manual session/demo switches, fictitious accounts, or prototype save/checkout state.
